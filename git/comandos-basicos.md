# Git: comandos básicos

## Iniciar um repositório
```bash
git init
```
Transforma a pasta atual num repositório Git.

## Adicionar alterações
```bash
git add .
```
Prepara todas as alterações para o próximo commit.

## Salvar as alterações (commit)
```bash
git commit -m "nome da alteração"
```
Cria um ponto salvo no histórico com a mensagem informada.

## Enviar para o repositório
```bash
git push
```
Sobe os commits para o GitHub.

## Pegar atualizações
```bash
git pull
```
Baixa o que tem de novo no GitHub.

## Mudar de branch
```bash
git checkout staging
```
Vai para a branch informada.
