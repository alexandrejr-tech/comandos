# Linux: atalhos do terminal

| Atalho | O que faz |
|---|---|
| `Ctrl + C` | Interrompe o comando que está rodando (não copia) |
| `Ctrl + U` | Apaga a linha inteira que está sendo digitada |
| `Ctrl + Shift + C` | Copia o texto selecionado |
| `Ctrl + Shift + V` | Cola (no Windows Terminal) |
| Botão direito | Cola (na janela padrão do Ubuntu) |
| `Tab` | Completa nomes de arquivos e pastas; se nada acontecer, o caminho está errado |
| Seta para cima | Volta para os comandos anteriores |

## Senhas
Ao digitar senha (`sudo`, `passwd`), nada aparece na tela. É normal.

## Silêncio é sucesso
Comandos que funcionam costumam não mostrar nada.
